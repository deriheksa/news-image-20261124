A newspaper front page that sums up Tuesday 24 November 2026 world news in a single image: 43 verified stories led by 3 heroes and 9 grid cards plus a below-map card, plus 30 ALSO briefs, a UTC timeline, a world map, and a date check. Every story is labelled by verification status (30 CONFIRMED, 11 REPORTED, 2 CLAIM), so what is confirmed reads as confirmed and what is still a claim reads as a claim.

`main.py` (pure Python standard library, no third-party packages) copies the pre-rendered `entry.png` to `/output/entry.png`.
